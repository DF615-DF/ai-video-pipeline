# MiniMax H3 提示词规范

## 一、H3 模型特点

- MiniMax H3 是统一多模态模型，能同时理解文本、图片、视频和音频，适合文生视频、图生视频、首尾帧和全能参考生成。
- 原生支持视频音频生成，不是画面生成完再加音效；提示词里要直接写“什么时候有对白、口型、环境音、音效”。
- 输出规格通常为 4-15 秒片段、768P/2K、24fps，常见比例包括 16:9、9:16、4:3、1:1、3:4、21:9。
- 单段提示词有字符上限，约 7000 字符；所以一段只做一个明确动作节拍，长动作拆成多段。
- 它对“前后连续性”很敏感：上一镜头的结束状态，应写成下一镜头的开始状态；角色、服装、道具、时间、场景都要显式锁定。
- 它支持音频描述，声音要写成空间、位置和时序，例如“左侧溪水，远处鸟鸣，烟花升空时短暂静默，爆炸声后只留虫鸣”。

## 二、H3 提示词写法

### 1. 每段先写输出目标

先写风格、画幅、时长、画质和画面禁忌：

```text
日式二次元手绘动画风格，吉卜力水粉质感打底，叠加新海诚式柔光与漂浮粒子；低饱和度，手绘背景；非 3D、非 CGI。
输出：16:9 横版，768P 或以上，24fps，单段 6-10 秒；不要字幕、水印、Logo、片名。
```

### 2. 写“一致性锁”

每一段都要写清楚：

- 人物统一：同一个人使用同一张参考图，发型、五官、身材不变化。
- 年龄符合情节：当前幕是什么年龄，就写什么年龄，不能在本段内变老或变小。
- 服装前后一致：本段开始穿什么，结束还穿什么；换装只能发生在剧本明确允许的位置。
- 场景不穿帮：不出现本幕时间不存在的物品、反季节植物、错误建筑、错误施工状态。
- 时间不矛盾：季节、天气、晨昏、光源方向、道具状态要承接上一镜头。
- 道具状态连续：物品不能凭空出现、消失、换人持有；红围巾、草结这类信物要写清在谁手里。

### 3. 写“单一动作节拍”

一个 H3 片段只推进一个动作：

```text
动作顺序：結先伸手，再握住阿守递来的围巾，最后把围巾交到阿守手中；不要同时发生奔跑、摔倒、回头等第二动作。
```

动作必须按自然物理顺序发生：先出现原因，再出现结果；手脚、衣物、道具的接触顺序不能颠倒。

### 4. 写“音频描述”

本项目固定规则：只保留对白与场景音，不添加背景音乐。

```text
音频：阿守说“我等你”，声音从正前方来；环境音为远处太鼓、近处虫鸣、风铃；烟花升空时有短暂静默，随后是轰鸣；全程无背景音乐。
```

### 5. 把负面约束转成正向约束

不要只写“不要 3D、不要穿模、不要闪烁”，H3 更容易执行正向描述：

```text
手绘二维动画质感，人物五官稳定，动作流畅自然，画面无闪烁，人体结构正常，无多余手指，无文字无标注。
```

## 三、本项目固定锚点

- 结：红围巾全程跟随；不同阶段分别是小学制服、高中校服、大学衬衫外套、环保工作装。
- 阿守：银灰发色、浅色素衣或浅色和服/斗篷、清冷山感；任何阶段都不能变成普通人，也不要给身体或衣角加实体雾。
- 草结：在结身边；红色围巾到第六幕后由阿守保管；两件信物在第十幕共同放回神龛。
- 神龛：第一幕完整，第八幕破损，第九幕只剩残骸，第十幕重建完成。
- 时间线：雪夜 → 春田埂 → 夏溪边 → 盛夏校园 → 夏夜烟花 → 春车站 → 东京数季 → 秋回乡 → 雨与恢复 → 春日神龛。

## 四、音频总规则

- 所有片段都写“只保留对白与场景音，不加背景音乐”。
- 对白以原剧本台词为准，不为了生成方便改词。
- 环境音写清楚空间方位和强弱：远处、近处、左、右、先、后。
- 烟花段声音顺序：咻 → 短暂静默 → 轰；间隙保留空白。
- 第十幕最后：所有环境音逐渐消失，只留一声“結”，然后黑场。
