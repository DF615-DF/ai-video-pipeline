# 风景视频风格指南

> 基于长期投喂的抖音收藏风景图与多轮生成迭代，沉淀的**个人审美逻辑 + 可复用提示词**。
> 核心 vibe：**唯美治愈，带一丝悲伤；浪漫诗意，真实自然。**

![[风景审美DNA.svg]]

---

## 一、底层审美逻辑（最重要，生成前先读）

1. **真实感铁律**
   - **固定机位**，绝不运镜 / 推拉摇移（AI 运镜匀速无呼吸感，最露馅）。
   - 动态只来自**环境**：风吹花叶、云层缓流、水面波光、风车转动——不靠镜头拉动。
   - 质感要**真实不无菌**：胶片颗粒 + 自然偏色 + 大气 haze（水汽/薄雾）+ 透视柔和。**构图可干净，色彩不能干净无菌**（拒绝鲜亮完美、卡通、塑料感）。

2. **每帧只强调一个"美的地方"**
   - 花、云、光影、水面闪光、城市灯火……选一个做强，其余做干净陪衬。
   - 海面普通 → 让天空/花出彩；天空普通 → 让草地/花出彩；要素多和少都能漂亮，关键是有统一情绪。

3. **场景不单一，框架构图常用**
   - 水边、草地、花田、天空、城市海边、电线日落都能用。
   - 花拱门 / 花枝 / 栏杆 / 树冠 / 窗户做**天然画框**，聚焦"美的地方"。

4. **色彩严格跟随时段**
   - 晴朗白天：鲜明、蓝绿清晰、亮度高。
   - 黄昏 / 日落：灰暗、柔和、暖橘 vs 青蓝的冷暖对比，不要强行鲜艳。
   - 蓝调 / 夜：暗调、灯火、剪影。

5. **主体永远是"景"**
   - 花、云、光影、水面、天空、城市轮廓……不是人或动物。
   - **不生成动物**（假、抢戏）。
   - **人物极克制**（见下方规则），且"与人相关"已基本收尾，非必要不出现。

6. **参考图足够明确时，直接图生视频（image-to-video）**
   - 文字硬堆复杂构图（远山 / 中景层次 / 树冠 / 浅景深对焦）极易做成"设计感强、假"。
   - 有明确参考图时，把图当首帧让 AI 照着学，提示词只补微动与氛围。

## 二、人物规则（仅当需要时 · 严格遵守）

> 用户已明确"与人相关的内容到此为止"，下面的规则只在你主动要人物时用。

- 只在**黄昏 / 傍晚 / 蓝调**出现；白天纯景不要人。
- **位置灵活不居中**：侧边、一角、偏下均可，没人规定在屏幕中央；要有"人恰好在那儿、被黄昏自然笼罩"的**抓拍感**，不是摆拍。
- **背影 / 半侧脸 / 侧身**，绝不正面、绝不清晰露脸；脸藏阴影 / 逆光 / 柔焦朦胧里，**适度模糊**。
- 偏暗剪影、松弛不僵硬、有**活人感**；**风吹头发**是允许的细腻动态。
- 人与天空间加**窄窄的暗色过渡层**（远山 / 树梢 / 低矮建筑），占比小、压低，不抢戏。
- 横幅画面**不要太空旷**：人物若在侧边，另一侧用景物（树丛 / 礁石 / 栏杆 / 草丛）填充。
- 光柔和自然，**不要放射光束 / 过曝太阳**；颜色浑浊（灰褐 / 脏橘 / 暗蓝 / 雾白），不是干净色块。
- 核心是"情绪"：人是情绪容器，景是放大器。

## 五、方法论经验（踩坑总结）

- **固定机位 > 运镜**：AI 运镜最易露馅，固定 + 自然动态最稳。
- **复杂构图别用文字硬堆**：远山 / 中景层次 / 树冠 / 浅景深对焦这类，文字描述出来 AI 容易做成"假"。有明确参考图就直接图生视频。
- **"设计感"太强 = 不自然**：避免堆"壮丽""眼前一亮""电影背景板"；追求"随手拍到、人/景偶然入画"的抓拍感。颜色要浑浊而非干净色块。
- **动态要克制**：花枝轻摇、云极缓移、水面微波即可，避免"大尺度风吹""快速云流"。
